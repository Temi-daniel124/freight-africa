# Freight Africa

Prepaid, escrow-protected full-truckload freight on Nigerian corridors. One installable web app for
shippers, truck owners, drivers, agents and staff.

- **Start here:** `AGENT.md` (how to work in this repository) and `docs/PROJECT-STATE.md` (where the
  build stands).
- **Documents, highest authority first:** `docs/DECISIONS.md` · `docs/PRODUCT.md` ·
  `docs/DATA-MODEL.md` (+ `docs/SYSTEM-LOGIC.md`) · `docs/ARCHITECTURE.md` ·
  `docs/ROLES-AND-PERMISSIONS.md` · `docs/PLATFORM-SCOPE.md` (+ `docs/planning/`) · `docs/PROJECT-STATE.md` ·
  `docs/DEVELOPMENT-WORKFLOW.md` · `docs/TOOLING-POLICY.md` · `AGENT.md` · `CLAUDE.md` · `BUILD.md` ·
  `SECURITY.md` · `DESIGN_SYSTEM.md`.

Stack: Next.js on Vercel · Supabase (project `czlowhaycaivpgimcefk`) · Bachs · Didit · WhatsApp Cloud
API · Resend. No Docker on the development laptop; database tests run in GitHub Actions.
